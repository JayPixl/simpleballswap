# Changelog

Player-facing release notes. The release workflow publishes the section whose heading matches the release version, verbatim, to every listing on Modrinth and CurseForge. Write about what players will notice and why it matters; leave commits, refactors, CI, and dependency bookkeeping out unless a player would see the difference.

Use the categories `Added`, `Changed`, `Fixed`, and `Removed`, newest release first. A release cannot be tagged until its section exists.

## [Unreleased]

## [1.2.0] - 2026-10-26

First release on Modrinth and CurseForge.

### Added

- Shift + right-click a Pokémon while holding a ball to open Cobblemon's interaction wheel and change the ball it was caught in.
- Options to consume the new ball and to return the old one, in `config/simpleballswap.json`.

### Changed

- Updated for Cobblemon 1.8, built and tested against 1.8.3. Requires Cobblemon 1.8.0 or newer on both Fabric and NeoForge.
